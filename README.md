# 📝 Python To-Do List

A simple command-line To-Do List application written in Python.

## Features

- Add tasks
- View tasks
- Mark tasks as completed
- Delete tasks
- Automatically saves tasks using JSON

## Technologies

- Python 3
- JSON
- File Handling

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/python-todo-list.git
```

Go into the project folder:

```bash
cd python-todo-list
```

Run the program:

```bash
python main.py
```
